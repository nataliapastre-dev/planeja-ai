# 💰 PlanejaAI — Planejador Financeiro Inteligente

> **PlanejaAI** é uma aplicação web desenvolvida para auxiliar no planejamento, organização e análise financeira pessoal, permitindo ao usuário visualizar sua renda, organizar despesas, definir objetivos e analisar diferentes possibilidades de planejamento.

---

# 📌 Sobre o Projeto

O **PlanejaAI** é uma aplicação web criada com o objetivo de transformar informações financeiras em uma visão mais clara, organizada e estruturada, facilitando o controle do orçamento e o planejamento de objetivos pessoais.

A ideia do projeto surgiu a partir da minha **experiência profissional na área administrativa**, período em que pude compreender, na prática, a importância do planejamento, da organização e do acompanhamento financeiro para a tomada de decisões.

Ao longo dessa experiência, também percebi que a necessidade de organização financeira não está presente apenas no ambiente empresarial. No âmbito pessoal, muitas pessoas enfrentam dificuldades para entender sua própria situação financeira, organizar despesas, estabelecer metas e planejar seus próximos passos.

Essa percepção despertou a ideia de unir dois conhecimentos que fazem parte da minha trajetória: **experiência administrativa e tecnologia**.

A partir disso, desenvolvi o PlanejaAI como mais do que um projeto acadêmico ou apenas uma aplicação para estudos. A proposta foi criar uma solução com **potencial de utilização em um contexto real**, capaz de transformar informações fornecidas pelo usuário em análises que auxiliem no planejamento financeiro.

Durante o desenvolvimento, busquei colocar em prática conhecimentos adquiridos tanto na minha experiência profissional quanto na minha formação em tecnologia, transformando conceitos teóricos em funcionalidades reais.

O projeto representa, portanto, a união entre:

> **Experiência administrativa + conhecimento de negócio + planejamento financeiro + análise de dados + tecnologia.**

O PlanejaAI também foi pensado com possibilidade de evolução. A partir de novas funcionalidades, persistência de dados, autenticação, dashboards, histórico financeiro e outras melhorias, a aplicação poderá se tornar uma solução ainda mais completa e acessível para diferentes perfis de usuários.

Mais do que desenvolver uma aplicação, o projeto representa a aplicação prática de conhecimentos adquiridos ao longo da minha trajetória, demonstrando como **experiências profissionais anteriores podem ser transformadas em ideias e soluções dentro da tecnologia**.

# 💡 Motivação

O projeto surgiu a partir da percepção de que muitas pessoas possuem informações sobre sua vida financeira, mas encontram dificuldades para organizar esses dados e transformá-los em um planejamento claro.

A partir dessa necessidade, surgiu a ideia de desenvolver uma aplicação simples e intuitiva capaz de reunir informações financeiras em um único ambiente e apresentar uma visão mais estruturada do orçamento.

O PlanejaAI também foi desenvolvido como uma oportunidade de aplicar conhecimentos de **desenvolvimento web, análise de dados, lógica de programação e integração entre diferentes tecnologias** em uma solução voltada para uma necessidade cotidiana.

A proposta central do projeto é:

> **Dados financeiros → análise → planejamento → tomada de decisão.**

---

# 🎯 Objetivo do Projeto

O principal objetivo do PlanejaAI é desenvolver uma ferramenta capaz de auxiliar o usuário a:

- Organizar sua renda mensal;
- Registrar e analisar despesas;
- Avaliar sua capacidade de economia;
- Definir objetivos financeiros;
- Estabelecer metas;
- Visualizar projeções;
- Analisar diferentes cenários;
- Receber recomendações baseadas nos dados informados.

Além disso, o projeto tem como objetivo aplicar conhecimentos técnicos relacionados ao desenvolvimento de aplicações web e à transformação de dados em informações úteis para o usuário.

- Investimentos;
- Aquisição de bens;

## 📊 Análise Financeira

A aplicação utiliza os dados informados para apresentar uma visão estruturada da situação financeira.

A análise considera informações como:

- Renda;
- Despesas;
- Saldo disponível;
- Capacidade de economia;
- Objetivo definido;
- Prazo planejado.

A partir desses dados, o sistema apresenta informações que podem auxiliar na organização e no planejamento financeiro.

---

## 🤖 Análise Inteligente

O projeto possui uma camada de análise destinada a transformar os dados financeiros fornecidos pelo usuário em informações e recomendações mais compreensíveis.

A proposta é utilizar os dados de entrada para identificar possibilidades de organização financeira e apresentar sugestões relacionadas ao objetivo informado.

> ⚠️ As informações apresentadas pelo sistema possuem caráter educacional e de planejamento, não constituindo recomendação financeira ou de investimento.

# 🧗 Desafios Enfrentados

Durante o desenvolvimento do PlanejaAI, alguns dos principais desafios estiveram relacionados à transformação de conceitos financeiros em regras que pudessem ser interpretadas pela aplicação.

### 🧩 Transformação de regras em lógica

Um dos desafios foi transformar conceitos como renda, despesas, saldo disponível, metas e capacidade de economia em regras de programação capazes de gerar resultados coerentes.

### 📊 Organização dos dados

Foi necessário estruturar as informações fornecidas pelo usuário de maneira que pudessem ser utilizadas tanto para cálculos quanto para a geração das análises.

### 🔄 Integração entre as camadas

Outro desafio foi trabalhar a comunicação entre a interface e a camada responsável pelo processamento das informações, garantindo que os dados inseridos pelo usuário fossem corretamente enviados e processados.

### 🎨 Experiência do usuário

Além da parte lógica, foi necessário pensar na apresentação das informações de forma simples e intuitiva, evitando que uma grande quantidade de dados financeiros tornasse a aplicação confusa.

### 📱 Responsividade

A interface foi desenvolvida considerando diferentes tamanhos de tela, buscando manter uma experiência consistente em dispositivos desktop e mobile.
